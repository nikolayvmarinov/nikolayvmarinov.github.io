Intro Py: Workshop Part I

Nikolay Marinov

This six-hour workshop, divided into two sessions, is a practical introduction to Python for people with no prior experience. Participants will be able to interpret, modify, and create scripts, run models, save output - and will have a foundation for further learning.

Plan:

00. Github: a general introduction to data communuty's go to place for storing and sharing code

01. Where to run Python

02. Write, run, and troubleshoot simple code

03. Variables, data types

04. Control structures, conditionals and loops

05. Lists, dictionaries, user input

06. Functions, modular code

07. Loading data and saving data

08. Py extensions: for "statistics", language analysis, visuals

09. Py: how polisci currently uses it for research and automation
